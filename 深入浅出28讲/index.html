深入浅出28讲

每一讲先打个比方入门，再按原文的顺序把完整设计思路走一遍：
搞清问题 → 画出大框架 → 逐个零件深入 → 权衡与坑 → 记住 3 点。

像爬楼梯一样读：打底子 01–03 → 造零件 04–08 → 搭系统 09–15 → 地理与数据 16–21 → 真金白银 22–28

第一阶段 · 打底子先建立三个基本功：怎么长大、怎么估算、怎么答题
01从一台电脑到一百万用户Scaling一个小网站怎样一步步长大，伺候得了一百万个用户。这是全套课程的总路线图。 02信封背面的估算Back-of-the-Envelope在信封背面花几分钟，算出系统要多大、多快——面试与设计的第一道工序。 03面试四步走System Design Framework45 分钟里按固定四步答题：范围 → 高层 → 深挖 → 总结，不慌不忙不跑偏。
第二阶段 · 造零件五个百搭小零件，几乎每套系统都要用
04限流器：门口的闸门Rate Limiter每人每分钟只能来几下，防挤爆、防捣乱，还能保证公平。 05一致性哈希：围成圈分糖果Consistent Hashing加一台服务器只动一小部分数据，而不是全部重排。 06键值存储：全班共用的大字典Key-Value Store存千亿词条，坏几台机器也不丢数据——Redis、DynamoDB 的底层地图。 07唯一 ID：不发重的学号Unique ID Generator几万台机器同时发号，全宇宙唯一，还能按时间排大小。 08短链接：给网址起小名URL Shortener把长网址压成几个字符，点它就能跳回去。
第三阶段 · 搭系统零件攒成七套真实世界的大系统
09网络爬虫：派机器人搬网页Web Crawler把全网的网页搬回家，给搜索引擎当原料。 10通知系统：不丢信的小邮局Notification System每天发上千万条推送、短信、邮件，不丢、不重、不扰民。 11信息流：朋友圈怎么送达News Feed System你发了帖子，好友的动态页怎么立刻出现它——扇出难题的混合解法。 12聊天系统：一直接通不挂的电话Chat System几亿人实时互发消息，还能看到对方"在线"。 13搜索补全：猜你想搜的目录树Search Autocomplete刚敲两个字母就猜出你想搜什么，100 毫秒内给出答案。 14YouTube：视频的搬运与变身Design Youtube几亿人上传和看视频，关键是转码流水线和省下 CDN 的钱。 15网盘：切块、去重、同步Google Drive文件存云上，手机改了电脑立刻看到，而且只传改动的部分。
第四阶段 · 地理与数据位置、地图、传话、体检、点钞——数据真正流动起来
16附近商家：给地球画格子Proximity Service打开 App 一搜，5000 米内的奶茶店立刻列出来。 17附近好友：叮，朋友在你身边Nearby Friends好朋友走进你 5 英里内，你的手机立刻"叮"一声。 18Google 地图：一叠会放大缩小的照片Design Google Maps把全世界的路装进手机，能放大缩小，还能秒算导航。 19消息队列：巨大的传话本Distributed Message Queue这头写、那头读，各忙各的互不打扰——Kafka 的完整解剖。 20监控告警：给机器量体温Metrics Monitoring & Alerting给十万台机器量体温，谁发烧就打电话叫醒工程师。 21广告点击计数：流水线点钞票Ad Click Event Aggregation每秒几万次点击，几分钟内算出每个广告被点了多少次——收钱的依据。
第五阶段 · 真金白银钱和订单进场：一分钱不能错，一毫秒不能慢
22酒店预订：最后一间房归谁Hotel Reservation抢订最后一间房，绝不能让两个人同时订到，还允许适度超售。 23电子邮件：五十年老邮局Distributed Email Service给十亿人做邮箱：收发、存储、搜索，一天几百 PB。 24对象存储：图书馆的合订本S3-like Object Storage存天文数字的文件，坏多少台机器都不许丢，还要越存越省。 25排行榜：自动排队机Real-time Gaming Leaderboard百万玩家实时冲榜，查"前十名"和"我排第几"都要飞快。 26支付系统：一分钱都不能错Payment System收钱这件事，重来一百次也不能重复扣款。 27数字钱包：记日记的账房Digital Wallet每秒一百万笔转账，账要平、历史要能查、还能从头重放。 28股票交易所：毫秒定胜负的拍卖行Stock Exchange每秒 21 万笔订单，比快、比公平，撮合不能错一拍——全部 27 讲的集大成者。
